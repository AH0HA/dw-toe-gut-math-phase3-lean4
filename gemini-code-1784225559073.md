# Technical Glossary[cite: 1]
*   **Aetheric refractive index (8):** A small dimensionless parameter used in the framework to represent departure from perfect superfluid coherence.[cite: 1]
*   **Breadth:** The extent of coherent coupling across a system.[cite: 1]
*   **Charge metabolism:** The proposed conversion of normal-fluid entropy back into superfluid order.[cite: 1]
*   **Coherence ceiling:** The maximum complexity a standing wave can sustain before phase-locking fails.[cite: 1]
*   **Concentration:** The local intensity of still-point realization.[cite: 1]
*   **Differentiation:** The number of distinct, specialized subsystems active within one standing wave.[cite: 1]
*   **Phase conjugation:** Complex conjugation of the order parameter, reversing velocity fields and defining the still-point condition \Psi=\Psi^{*}.[cite: 1]
*   **Still point:** A phase-conjugate fixed point where velocity vanishes, symmetry is highest, and the framework places the deepest analogue of consciousness.[cite: 1]
